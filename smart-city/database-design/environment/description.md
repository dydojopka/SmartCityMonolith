# БД Environment

Файл: `/data/environment.db`. Идентификаторы - UUID, даты - UTC.

| Таблица | Назначение |
|---|---|
| `sensors` | Название, тип, единица измерения, координаты, хеш ключа, статус и последний контакт |
| `sensor_readings` | Значение показания, датчик, время измерения и приёма |

Связь: `sensor_readings.sensor_id → sensors.id`.
Составной индекс `(sensor_id, measured_at)` используется для истории показаний.
Статусы датчика - `ACTIVE`, `INACTIVE`; ключ хранится только как хеш.
Сохранение показания и обновление последнего контакта выполняются вместе.
Связей с чужими БД нет.
