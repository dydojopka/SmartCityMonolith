# Ашроев Евгений — zheNYA

## Выполненная часть

- Общая инфраструктура монолита на FastAPI, SQLAlchemy и SQLite.
  Настройка сессий, хранение времени в UTC, JWT и проверка ролей.
- API-контракт, подключение модулей Utility и Notification, инициализация
  таблиц и заполнение демонстрационными данными.
- Конфигурации Docker Compose для полного города и изолированных стендов.
  Копия исходного SmartCity и микросервисный стенд для замеров.
- Тестовая инфраструктура с временными SQLite-файлами и интеграционные
  проверки. В полном городе проверены вызовы Notification от Transport
  и Billing.

Код и проверки описаны в [техническом обзоре](../PLAN.md).
Исходники для сравнения описаны в [документе о переносе](../SMARTCITY_ORIGIN.md).
