# Smart City

Шесть FastAPI-микросервисов и React-интерфейс для пользователей, транспорта,
парковок, заявок ЖКХ, экологических показаний и счетов.

## Запуск

Требуются Docker и Docker Compose. Команды выполняются из `smart-city/`:

```bash
cp .env.example .env  # только если .env ещё нет
docker compose up --build -d
```

Сайт: <http://localhost:5173>. Остановка с сохранением БД: `docker compose down`.
Для старых БД с несовместимой схемой нужна [миграция](docs/MIGRATION.md).

## Сервисы

| Сервис | Назначение | Порт |
|---|---|---:|
| Identity | Регистрация, вход, пользователи | 8001 |
| Transport | Транспорт, парковки, бронирование | 8002 |
| Utility | Заявки ЖКХ и их статусы | 8003 |
| Environment | Датчики и показания | 8004 |
| Billing | Счета и платежи | 8005 |
| Notification | Внутренние уведомления | 8006 |

Swagger: `http://localhost:<порт>/docs`. Состояние сервиса: `/health`.
Каждый сервис имеет собственный SQLite-файл и Docker volume; чужие БД недоступны.
Transport, Utility и Billing вызывают Notification по HTTP после сохранения операции.
Ошибка уведомления не отменяет бронь, изменение заявки или оплату.

## Демонстрационные аккаунты

Общий пароль: `demo12345`.

| Роль | Email | Возможности |
|---|---|---|
| USER | `user@smartcity.local` | Свои заявки и счета, бронирование, оплата |
| OPERATOR | `operator@smartcity.local` | Все заявки и изменение их статусов |
| ADMIN | `admin@smartcity.local` | Управление статусами заявок, чтение чужих счетов через API |

Регистрация создаёт аккаунт USER. Демонстрационные данные добавляются при старте
без сброса существующих записей.

## Настройки `.env`

| Переменная | Назначение |
|---|---|
| `JWT_SECRET` | Общий секрет подписи JWT |
| `SERVICE_TOKEN` | Защита внутренних уведомлений и платёжного webhook |
| `SENSOR_API_KEY` | Ключ приёма показаний демонстрационных датчиков |
| `CORS_ORIGINS` | Разрешённый адрес сайта |
| `DEMO_PAYMENTS_ENABLED` | Серверная имитация оплаты; в Compose включена по умолчанию |

Не публикуйте `.env` и рабочие БД. Вне учебной среды замените секреты и отключите
демо-оплату. Изменение `SENSOR_API_KEY` не обновляет ключ уже созданного датчика.

## Оплата

Кнопка «Оплатить» создаёт платёж и запрашивает серверное подтверждение через
защищённый webhook. Счёт становится «Оплачен (PAID)», появляется дата оплаты.
Повтор после потери ответа использует тот же ключ и не создаёт вторую оплату.
Суммы в интерфейсе показаны в рублях (`2 450,00 ₽`), в API и БД - в целых копейках.
Деньги не списываются; `SERVICE_TOKEN` не передаётся браузеру.
