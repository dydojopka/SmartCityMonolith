# Шилов Данил — daNYA

## Выполненная часть

- Перенос создания, чтения и смены статусов заявок ЖКХ в модуль Utility.
  Сохранены прежний REST API, доступ по ролям и повтор запроса с ключом
  идемпотентности.
- Атомарное обновление статуса. После фиксации изменения Utility вызывает
  `NotificationApi.send`. Повтор того же статуса не создаёт уведомление.
- Тесты заявок, конкурентных запросов и обработки сбоя уведомлений.
- Инструменты сравнения версий, три прогона на каждом стенде и эксперимент
  с отказом и восстановлением отправки.
